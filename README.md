# Peluche 10 Android

Aplicacion Android de Peluche 10, una mascota virtual con juego libre, portero, tiros y reacciones al movimiento del telefono.

## Abrir el proyecto

1. Abre la carpeta `android` en Android Studio.
2. Espera a que Gradle sincronice el proyecto.
3. Ejecuta la configuracion `app` en un emulador o telefono Android.

## Generar APK

En Android Studio usa `Build > Build APK(s)`.

El APK de desarrollo se genera en `app/build/outputs/apk/debug/app-debug.apk`.
